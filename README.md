# 출결 알림 전달기

우리반 출결 연락(문자·카톡)을 모아 **엣지 사이드 패널**에서 바로 보는 개인용 도구입니다.

```
갤럭시 폰 (출결 알림 전달기 앱)
  └ 우리반 형식 연락처의 문자·카톡만 골라 전송 → 결석/지각/조퇴 알림 버튼·입력창
        ↓
구글 시트 (Apps Script) ─ 데이터 저장소 역할
        ↓
엣지 사이드 패널 (출결 연락 패널) ─ 나이스 옆에 띄워 놓고 확인·입력 완료 체크
```

- 폰 앱 권한: 인터넷, 알림 접근, 알림 표시. 연락처·문자·위치 권한 없음
- 외부 라이브러리·광고·분석 모듈 0개
- 우리반 형식이 아닌 발신자의 알림은 저장하지도 보내지도 않음
- 폰 앱에는 시각·발신자·전송 결과만 기록하고 메시지 내용은 남기지 않음 (전송 실패 시 재전송 대기열에만 잠시 보관)

## 1. 구글 시트 준비
1. 새 구글 시트 → 확장 프로그램 → Apps Script → `apps-script/attendance_collector.gs` 붙여넣기
2. `SECRET` 값을 길고 랜덤한 문자열로 변경 (`CLASS_CODE`는 `26302` = 26년 3학년 2반)
3. `setup` 함수 실행 → 시트 메뉴 '출결정리 → 테스트 메시지 넣기'로 확인
4. 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스: 모든 사용자) → URL 복사

코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영됩니다(URL은 그대로).

## 2. 연락처 이름 규칙
- 학생: `2630201권민준` (카톡 친구 이름도 이 형식으로 보이는지 확인)
- 학부모: `#2630201권민준어머니` / `…아버지`
- 숫자 7자리 = 연도 2 + 학년 1 + 반 2 + 번호 2. 형식이 다르면(예: `#2603201…`) 걸러져 버려집니다.
- 내년: 앱의 '발신자 이름 패턴'과 Apps Script의 `CLASS_CODE`만 바꾸면 됩니다.

## 3. 폰 앱 설치
1. 저장소 → Actions → 최근 실행 → 맨 아래 Artifacts의 `attendance-relay-apk` 다운로드 (zip 안에 `app-debug.apk`)
2. 폰에서 APK 열기 → '출처를 알 수 없는 앱' 설치 허용
3. **제한된 설정 해제** (안드로이드 13 이상, 직접 설치한 앱에 필요):
   설정 → 애플리케이션 → 출결 알림 전달기 → 오른쪽 위 ⋮ → **제한된 설정 허용**
4. 앱 실행 → 알림 허용 → ① 알림 접근 권한 켜기 → ② 배터리 '제한 없음'
5. URL·비밀키 입력 → 저장 → 연결 테스트
6. 카카오톡·메시지 앱의 알림이 켜져 있고 **알림에 내용 표시**가 켜져 있는지 확인

### 유형 직접 입력
우리반 연락이 시트에 저장되면 폰에 알림이 뜹니다.
- **결석 / 지각 / 조퇴** 버튼: 한 번에 저장 (사유는 비워 둠)
- 알림 본문을 누르면 입력창: 유형(결석·지각·조퇴·결과·해당없음) + 사유(질병·미인정·기타·출석인정)
- 직접 고른 값은 '담임 확정'으로 저장되어 패널에 ✔ 표시로 우선 보입니다. 폰이 오프라인이면 나중에 자동 재전송됩니다.

## 4. 엣지 사이드 패널 설치
1. 엣지 주소창에 `edge://extensions` → 왼쪽 아래 **개발자 모드** 켜기
2. **압축 풀린 항목 로드** → `edge-extension` 폴더 선택
3. 툴바의 퍼즐 아이콘 → '출결 연락 패널' 고정(핀) → 아이콘 클릭하면 사이드 패널이 열림
4. ⚙ → Apps Script URL·비밀키 입력 → 저장하고 연결

패널 기능: 날짜 이동(‹ ›, 날짜 누르면 오늘), 학생별 카드(미입력 학생이 위로), '나이스 입력' 체크(시트에 반영), 1분마다 자동 갱신(편집 중에는 멈춤).

### 출결 카드와 기타 대화
- 출결 관련으로 보이는 메시지(결석·지각·조퇴·결과 표현, 아파·병원 등 사유 표현)는 **학생 카드**로 보입니다.
- 같은 학생의 잡담은 카드 안에 **"대화 n개 더 보기"**로 접혀 있습니다.
- 출결과 무관해 보이는 학생은 맨 아래 **기타 대화**에 접혀 있습니다. 놓친 출결 연락이 있으면 **출결로 전환**을 누르세요.
- 기타 대화도 시트에는 모두 저장됩니다(놓치지 않기 위해). 폰 알림은 출결 관련 메시지에만 뜹니다.

### 확정·수정
카드의 **입력**(입력 후에는 **수정**) → 유형·사유·**적용 날짜**·메모 → **저장**
- 적용 날짜를 바꾸면 카드가 그 날짜로 옮겨집니다.
- **출결 아님**을 누르면 기타 대화로 내려갑니다.
- "내일/모레/금요일/다음 주 월요일/11월 3일" 같은 표현은 적용 날짜를 자동 추정합니다. 오늘 받은 '내일 결석' 연락은 내일 화면에 카드로 나오고, 오늘 화면 위쪽 **다른 날짜로 넘어간 연락**에 한 줄로 표시됩니다(누르면 그 날짜로 이동).

### 직접 추가 (놓친 연락 넣기)
PC 카톡에서 먼저 읽어 폰 알림이 안 온 경우 등에 씁니다.
1. 패널 위쪽 **+ 직접 추가**
2. 번호 입력 → 이름 자동 표시 (한 번이라도 연락이 왔던 학생. 처음이면 이름 직접 입력)
3. 보낸 사람·유형·사유 선택, 카톡 메시지는 복사해 붙여넣기(선택)
4. **추가** → 지금 보고 있는 날짜로 기록되고, 담임 확정값(✔)으로 표시됩니다.

## 알아 둘 점
- 카톡을 PC에서 먼저 읽으면 폰 알림이 안 떠서 수집되지 않을 수 있습니다.
- 학교 업무용 PC는 개발자 모드 확장 프로그램 설치가 정책으로 막혀 있을 수 있습니다.
- 앱 업데이트: 코드를 바꿔 푸시하면 새 APK가 빌드되고, 같은 서명 키라 지우지 않고 덮어 설치됩니다.
