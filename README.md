# 출결 알림 전달기

갤럭시 폰에 온 문자·카카오톡 알림 가운데 **연락처 이름이 우리반 형식(`2630201권민준`, `#2630201권민준어머니`)인 발신자**의 메시지만 골라
선생님의 Google Apps Script(구글 시트)로 보내는 개인용 안드로이드 앱입니다.

- 권한: 인터넷 + 알림 접근. 연락처·문자·위치 권한 없음
- 외부 라이브러리·광고·분석 모듈 0개 (코드 전체가 `app/src/main/java/` 아래 4개 파일)
- 걸러지지 않은 알림은 저장하지도 보내지도 않음
- 앱 안에는 시각·발신자·전송 결과만 기록하고 메시지 내용은 남기지 않음 (전송 실패 시 재전송 대기열에만 잠시 보관)

## 1. 구글 시트 준비
1. 새 구글 시트 → 확장 프로그램 → Apps Script → `apps-script/attendance_collector.gs` 붙여넣기
2. `SECRET` 값을 길고 랜덤한 문자열로 변경 (`CLASS_CODE`는 `26302` = 26년 3학년 2반)
3. `setup` 함수 실행 → 시트 메뉴 '출결정리 → 테스트 메시지 넣기'로 확인
4. 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스: 모든 사용자) → URL 복사

명부 시트는 필요 없습니다. 번호·이름·관계(학생/어머니/아버지)를 연락처 이름에서 바로 읽습니다.

## 2. 연락처 이름 규칙
- 학생: `2630201권민준` (카톡 친구 이름도 이 형식으로 보이는지 확인)
- 학부모: `#2630201권민준어머니` / `…아버지`
- 숫자 7자리 = 연도 2 + 학년 1 + 반 2 + 번호 2. 형식이 다르면(예: `#2603201…`) 걸러져 버려집니다.
- 내년: 앱의 '발신자 이름 패턴'과 Apps Script의 `CLASS_CODE`만 바꾸면 됩니다.

## 3. APK 빌드 (GitHub Actions)
1. 이 폴더를 **Private** 저장소에 올리면 자동으로 빌드가 시작됩니다.
2. 저장소 → Actions → 최근 실행 → 맨 아래 Artifacts의 `attendance-relay-apk` 다운로드 (zip 안에 `app-debug.apk`)

## 4. 폰에 설치
1. APK를 폰으로 옮겨 내 파일 앱에서 열기 → '출처를 알 수 없는 앱' 설치 허용
2. **제한된 설정 해제** (안드로이드 13 이상, 직접 설치한 앱에 필요):
   설정 → 애플리케이션 → 출결 알림 전달기 → 오른쪽 위 ⋮ → **제한된 설정 허용**
3. 앱 실행 → ① 알림 접근 권한 켜기 → ② 배터리 '제한 없음'
4. URL·비밀키·접두어 입력 → 저장 → 연결 테스트
5. 카카오톡·메시지 앱의 알림이 켜져 있고 **알림에 내용 표시**가 켜져 있는지 확인

## 알아 둘 점
- 카톡을 PC에서 먼저 읽으면 폰 알림이 안 떠서 수집되지 않을 수 있습니다.
- 폰이 오프라인이면 대기열에 보관했다가 다음 알림이 오거나 앱을 열 때 다시 보냅니다(최대 3일).
- 업데이트: 코드를 바꿔 푸시하면 새 APK가 빌드되고, 같은 서명 키라 지우지 않고 덮어 설치됩니다.
